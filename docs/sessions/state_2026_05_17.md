## ARCHITECTURAL FIXES APPLIED THIS SESSION

These fixes are now locked into seed_shopify.py and must be
carried forward into all subsequent seed scripts:

### Fix 1 — is_synthetic removed from raw table inserts
DEBT-006 resolved correctly. is_synthetic lives in staging
tables only. Raw table inserts do not include this column.
Synthetic data identified via client_config.use_synthetic_data.

### Fix 2 — Airbyte metadata columns required on all raw tables
All 9 Airbyte-managed raw tables require four NOT NULL columns:
- _airbyte_raw_id: uuid4() string per row
- _airbyte_extracted_at: row's created_at timestamp
- _airbyte_meta: {}
- _airbyte_generation_id: 0

Helper function `airbyte_meta_cols()` generates all four.
Every subsequent seed script must call this helper for all
Airbyte-managed raw table inserts.

### Fix 3 — Single transaction boundary wraps all 14 functions
All seeding functions execute inside one transaction.
Any crash rolls back everything. No partial commits possible.
ON CONFLICT DO NOTHING (bare form) on all raw table inserts.
Do NOT use ON CONFLICT (column_name) — no UNIQUE constraints
exist on Airbyte-managed raw tables.

### Fix 4 — Nearest PD projection for correlation matrix
CORR_MATRIX was not positive definite.
Fixed via eigenvalue clipping (negative eigenvalues → 1e-6,
matrix reconstructed and re-symmetrised).
Cholesky decomposition now stable.
Apply same fix to Meta and TikTok seed scripts which use
the same correlation structure.

### Fix 5 — GENERATED ALWAYS identity columns
public.alert_log.id is GENERATED ALWAYS AS IDENTITY.
Do not insert explicit id values. Drop id from cols list
and let Postgres auto-generate. Apply to all tables with
identity columns in subsequent seed scripts.

### Fix 6 — Raw tables do not exist until seed script creates them
Airbyte-managed raw tables only exist after a real Airbyte
sync. Since Azure & Co is synthetic (no real Shopify store),
seed scripts must CREATE TABLE IF NOT EXISTS before inserting.
Use exact Airbyte schema: all four metadata columns NOT NULL.
