- Monitor-and-Wait: E2, E3, E4, D2, B3, G2, G3, E1
- Diagnostic-Only: A4, D6, F3 (weather events), H1, H2, H3

### Alert 3 Two-Stage Design
- Stage 1 fires Day 7 (early estimate, Cohort A only, return window open)
- Stage 2 fires Day 21 (confirmed, Cohort A + B, returns + Klaviyo value)
- Every influencer activation: two alert_log rows required

### COGS Architecture (Three-Tier)
- Tier 1: Finaloop CSV export → sku_cost_master (gold standard)
- Tier 2: Shopify inventory_items.cost + landed cost multiplier
- Tier 3: Founder-stated blended gross margin % by category
- Confirmation flow: 5 questions (not 8)
- No Finaloop Airbyte connector (no public API)

### Suppression Architecture
- Four states: Fire / Fire with Context / Suppress+Explain / Suppress+DQ Flag
- 50 suppression scenarios (S1–S50)
- brand_event_calendar drives all suppression logic
- Suppression confidence decays over time (not hard cutoffs)
- Component-level suppression for Alert D1 (CPM/return/COGS/discount/ops)

### DQ Architecture
- Multi-dimensional: dq_metric_scores replaces single client_config score
- Weighted confidence per alert type (16 alert types have weight tables)
- 6 cascade chains with exact timing values
- DQ improvement arc: 81 (Month 1) → 93 (Month 24)
- H11–H19 alerts covering DQ monitoring and improvement
