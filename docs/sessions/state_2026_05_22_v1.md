## KNOWN LIMITATIONS — CARRY FORWARD

### B-10 — Explorer segment_pct_of_total_revenue = 0% (synthetic data artifact)
Explorer customers placed their only order >90 days before the observation
date in synthetic data, so they fall outside the trailing 90-day revenue window.
Real client data will always have fresh first purchases within the window.
Agent B must NOT fire on Explorer revenue share = 0% without first checking
whether the client has had new customer acquisitions in the trailing 90 days.
Sample confirmation: 2025-10-15 → Explorer 0.0% of 90d revenue (seed artifact).

### B-9 — Inventory columns point-in-time only
shopify_inventory_levels snapshot exists for 2026-05-31 only.
Columns 6–11 (stockout_sku_count through top_sku_inventory_units_pct) will be
NULL for all other dates until real client data provides daily snapshots.
Agent B must not fire G-series inventory alerts until time-series coverage > 30 days.

### B-9 — top_sku_inventory_pct = NULL
SKU format mismatch: sku_cost_master uses text SKU (AZR-DRESS-HERO-01-XS),
shopify_inventory_levels uses integer inventory_item_id.
B-4 builds the alias map to bridge these. Blocked until B-4 executes.

### Google Ads Fix 5 — cost_micros rounding (Agent D disclosure only)
PostgreSQL exact arithmetic means rounding divergence does not appear in DB.
Real-world divergence exists in Google's own reporting layer vs API.
Fix is Agent D Evidence Stack Layer 0 disclosure for all G-series spend alerts:
"Google Ads spend figures may differ from your dashboard by <$0.50/day due
to ad-set level rounding in Google's reporting layer."
30 split rows in DB are structural demonstration only — not a mart SQL issue.

### B-4 — Dropped signals (confirmed out of scope this session)
1. ROAS < 1.0 pause recommendation — dropped. Too many confounding variables
   (inventory, seasonality, competition). Never recommend pausing on a single
   metric without multi-signal confirmation + Layer 3 historical precedent.
2. Upper-funnel CPM → organic lift correlation — dropped. Pre/post without
   proper AB is directional noise. Too many confounders (seasonality, PR events,
   competitor activity). PS does not comment on awareness campaign effectiveness
   via organic lift correlation.
